# NagarSeva-AI

AI-powered civic infrastructure issue detection system using YOLO and modern web tech.

## Directory Structure

- `backend/`: FastAPI backend service
- `frontend/`: Web interface
- `datasets/`: Dataset storage for model training
- `models/`: Trained model weights & exports
- `notebooks/`: Jupyter notebooks for data analysis & experiments
- `training/`: Training scripts (e.g., `training/road_damage/`)
- `docs/`: Project documentation
